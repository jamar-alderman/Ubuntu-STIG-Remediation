# Ubuntu 24.04 STIG Remediation Lab

## Overview

This project documents the remediation of DISA STIG findings on an Ubuntu Server 24.04 virtual machine. The objective was to improve system security by implementing Linux hardening techniques and validating the results after remediation.

---

## Objectives

- Harden SSH configuration
- Configure auditd
- Configure UFW firewall
- Implement AIDE
- Apply DISA STIG recommendations
- Verify successful remediation

---

## Lab Environment

| Component | Details |
|-----------|---------|
| Hypervisor | KVM/QEMU |
| OS | Ubuntu Server 24.04 |
| Management | SSH |
| Compliance | DISA STIG |
